# 交付与验收

<span class="level level-optional">⚪ 第 8 节</span>

开发侧交付代码，测试侧按清单验收，两端都只以本规范的数值为准。

## 8.1 开发侧

<ul class="rules">
  <li class="must">所有样式引用 Token（CSS 变量），禁止硬编码颜色、字号、间距、圆角、阴影。</li>
  <li class="must">Token 只在全局定义一次，组件内不重新赋值覆盖语义色。</li>
  <li class="must">组件交付时包含全部状态样式（见<a href="/components/button">按钮</a>的状态表）。</li>
  <li class="recommend">Token 文件单独维护（如 <code>tokens.css</code>），按「色彩 / 字体 / 间距 / 圆角阴影」分组并加注释。</li>
  <li class="recommend">新增 Token 前先确认已有 Token 无法覆盖，避免同义 Token 膨胀。</li>
</ul>

### 自查命令

提交前用正则扫一遍硬编码，命中即需修正：

```bash
# 硬编码颜色
grep -rnE "#[0-9a-fA-F]{3,8}\b|rgba?\(" src --include="*.vue" --include="*.css" \
  | grep -v "tokens.css"

# 非法字号
grep -rnE "font-size:\s*(13|15|17|18)px" src

# 非法间距
grep -rnE "(margin|padding)[^:]*:\s*(5|6|7|9|10|11|13|14|15|18|25|30)px" src
```

## 8.2 测试侧走查清单

逐项打勾，任一 <span class="level level-must">强制</span> 项不通过，验收即为不通过。

### 色彩

<ul class="checklist">
  <li>页面中不存在规范外的色值（可用取色器抽查 5 个元素）</li>
  <li>主按钮、链接、选中态均为 <code>--color-primary</code> 系列</li>
  <li>错误、成功、警告三类提示分别使用对应语义色</li>
  <li>禁用态文字为 <code>--color-text-disabled</code>，且可辨识为「不可用」</li>
</ul>

### 排版

<ul class="checklist">
  <li>页面内字号只出现 20 / 16 / 14 / 12 四档</li>
  <li>字重只出现 400 与 600</li>
  <li>多行文本行高一致，无挤压或过疏</li>
</ul>

### 间距与布局

<ul class="checklist">
  <li>所有间距为 4 的倍数，且落在允许值内</li>
  <li>左侧菜单 200px（折叠 64px）、顶部导航 90px</li>
  <li>内容区左右留白 24px，各页面一致</li>
  <li>同一容器上下内边距相等</li>
</ul>

### 圆角与阴影

<ul class="checklist">
  <li>圆角只有 2 / 4 / 8px 三档</li>
  <li>阴影只用于浮层，平面内容无阴影</li>
  <li>弹窗用 <code>--shadow-modal</code>，卡片用 <code>--shadow-card</code></li>
</ul>

### 动作色与标签

<ul class="checklist">
  <li>12 个动作按钮的颜色与 6.3.2 动作色板一致（查询蓝、重置橙、暂存琥珀、自定义青、撤回绿、删除红、取消灰）</li>
  <li>工具条按钮顺序：查询 → 重置 → 自定义 在最左，关闭 / 删除 在最后</li>
  <li>同类动作在不同页面同色，未自造新色</li>
  <li>表格操作列 ≤3 项用文字按钮：次要动作灰、主动作蓝且在最后；≥4 项收进「更多」</li>
  <li>同一状态标签在全站同色，且带文字</li>
  <li>状态标签为浅底 + 描边，无实心填充</li>
</ul>

### 组件状态

<ul class="checklist">
  <li>按钮 5 个状态全部实现（default / hover / active / disabled / loading）</li>
  <li>同一区域只有一个主按钮</li>
  <li>表单标签顶部对齐，必填星号在 Label 前</li>
  <li>错误提示在输入框下方且为红色</li>
  <li>表格操作列固定右侧，水平滚动时不动且背景不透明</li>
  <li>空数据有完整空状态：插画 + 结论 + 可执行动作</li>
  <li>表头字号（14px/600）不小于表体，表头底色为 <code>#FAFAFA</code></li>
  <li>9 列流程表列顺序为 序号 → 标题 → 属性 → 状态 → 进度 → 操作，状态列用标签</li>
  <li>行内进度为「条 + 百分比」，条 <code>156×10</code>，百分比在右且等宽，100% 不变绿</li>
  <li>弹窗按钮「取消在左、确认在右」</li>
  <li>弹窗遮罩为 <code>rgba(0,0,0,0.4)</code></li>
  <li>提示条上下左右居中，成功绿底、失败红底，图标为实心圆 + 白色图形</li>
  <li>图标按钮 32×32，有 <code>title</code> 或 <code>aria-label</code>，展开/收起成对出现</li>
  <li>进度条为胶囊轨道，百分比在右侧且等宽；填充始终保持品牌蓝，不变色</li>
  <li>404 / 403 / 500 使用统一异常版式，并提供返回出口</li>
  <li>骨架形态全站统一（侧边 / 顶部 / 混合，不混用），顶栏 56px、一级导航 44px、页签 40px</li>
  <li>侧边导航展开 232px / 收起 64px，收起后保留图标与 <code>title</code>，状态持久化</li>
  <li>侧边选中项整行铺品牌蓝；一级导航选中为半透明白底；不出现第二种选中语言</li>
  <li>页签首页按钮固定最左不可关；最多 8 个，超出横向滚动；关闭后按「右 → 左 → 首页」切换</li>
  <li>列表页三段同宽同边距：筛选卡 → 表格卡 → 分页；筛选与表格之间不留断档</li>
  <li>筛选后无结果走空状态 + 「清除筛选」；条件变化回到第 1 页并保留已填条件</li>
  <li>一般列表时间右对齐且等宽；同一行只用一种未读标识（NEW 角标 或 状态标签）</li>
  <li>数据卡同屏 ≤ 6 张、三等分；卡内文字纯白，颜色只表达业务分类且全站固定</li>
</ul>

### 交互与可访问性

<ul class="checklist">
  <li>可点击区域不小于 32px</li>
  <li>正文对比度 ≥ 4.5:1，大字号 / 图标 ≥ 3:1</li>
  <li>动效时长 200ms，无布局属性过渡</li>
  <li>键盘可完成全部操作，焦点可见</li>
  <li>状态不单靠颜色传达</li>
</ul>

## 8.3 常见缺陷对照

| 缺陷 | 违反条款 | 修正方式 |
| --- | --- | --- |
| 按钮只做 hover，无 active | 6.3 状态 | 补 `--color-primary-active` |
| 表格行浅蓝悬停，菜单 / 页签 / 列表行仍是灰悬停 | 2.3 色彩令牌 | 白底悬停统一 `#E6F3FE`（`--color-bg-hover-blue`） |
| loading 期间仍可点击 | 6.3 状态 | 加 `disabled` 并拦截提交 |
| 表单标签左对齐 | 6.4 表单 | 改为顶部对齐，间距 8px |
| 必填星号在 Label 之后 | 6.4 表单 | 移到 Label 前 |
| 表格操作用彩色图标按钮 | 6.5 表格 | 改为文字按钮或 Chip |
| 重置按钮用了灰色 | 6.7 动作色板 | 改 `--color-action-warning` |
| 暂存与提交同为蓝色 | 6.7 动作色板 | 暂存改 `--color-action-hold` |
| 同一状态两种颜色 | 6.8 状态标签 | 按色板表统一 |
| 提示条贴在页面顶部 | 6.9 轻提示 | 改为上下左右居中 |
| 提示图标是线框图标 | 6.9 轻提示 | 改为实心圆 + 白色图形 |
| 查询无结果时留白 | 6.12 空状态 | 补空状态三件套 |
| 表头 12px 或与表体同号同重 | 6.5 表格 | 表头改 14px / 600 + 灰底 |
| 进度条直角、百分比写在条内或完成时变绿 | 6.11 进度条 | 改全圆角，百分比移到右侧，填充保持品牌蓝 |
| 404 只显示一行英文 | 6.13 异常页 | 换统一插画 + 人话 + 返回按钮 |
| 侧边选中项用「左竖条 + 浅底」 | 6.1 全局组件 | 改为整行品牌蓝铺底 + 白字 |
| 收起侧栏后只剩空白或半个文字 | 6.1 全局组件 | 保留 64px 图标轨道 + <code>title</code> 名称 |
| 页签可关闭到没有首页 | 6.1 全局组件 | 首页按钮固定最左、不可关闭 |
| 筛选卡比表格窄一截、边距不一致 | 6.2.1 表格页 | 三段同宽同边距，卡片内边距统一 14/16 |
| 列表页另画一套顶栏与侧边 | 6.2.1 表格页 | 内容写进骨架默认插槽，不重复实现头部 |
| 日期右对齐但数字不等宽，标题被挤成锯齿 | 6.2.2 一般列表 | 时间用 tabular-nums 右对齐，标题单行省略 |
| 一行里同时出现 NEW 角标和「未读」标签 | 6.2.2 一般列表 | 只保留一种未读标识 |
| 数据卡颜色随数量变化 / 同业务两色 | 6.2.3 卡片列表 | 颜色按业务固定，不随数据变化 |
| 弹窗确认在左、取消在右 | 6.6 弹窗 | 调换顺序 |
| 背景色写 `#f5f5f5` | 2 色彩 | 改用 `--color-bg-page` |
| 间距 10px / 15px | 4 间距 | 就近取允许值 |
| 弹窗遮罩 `rgba(0,0,0,0.6)` | 6.6 弹窗 | 统一 `0.4` |

## 8.4 版本与变更

| 场景 | 处理 |
| --- | --- |
| 修改数值 | 同步更新源文件、本站、Trae 规则三处，升次版本号 |
| 新增规则或 Token | 标注强制等级与用途，升主版本号 |
| 废弃规则 | 保留条目并标注「已废弃 · 替代项」，不直接删除 |
