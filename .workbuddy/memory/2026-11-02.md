### 踩坑
- `.vp-doc a` 的链接色会覆盖 `.btn-primary` 的文字色，锚点按钮变成蓝底蓝字（看起来无文字）→ 需 `.vp-doc a.btn-primary { color:#fff }`。
- SVG 元素上 CSS animation 的 transform 会覆盖 `transform` 属性，旋转要拆成外层 `<g transform>` + 内层动画 `<g>`。
